# Hi, I'm Oluwayanmife
 
Third-year Computer Science and Engineering student at Obafemi Awolowo University, Nigeria. I like building things that fix problems I actually run into, whether that's a messy Downloads folder or comparing prices across stores. Security is a big part of what I do (I'm heading toward DevSecOps), but it's not the only thing I build.
 
## Things I've built
 
| Project | What it does |
|---|---|
| **[Vindex](https://github.com/Yanmife-source/Vindex)** | Web vulnerability scanner in Go. Authenticated crawling, passive header analysis, and active XSS and SQLi detection, tested against DVWA. |
| **[Price Comparison Bot](https://github.com/Yanmife-source/Price-Comparison-Bot)** | Telegram bot that compares product prices across stores. Python, Playwright, LangChain, Groq. |
| **[SwiftyEx](https://github.com/Yanmife-source/swiftyex-hackfest)** | Solo hackathon project: a Telegram bot with live exchange rates, keyboard navigation and inline refresh buttons. |
| **[Downloads organizer](https://github.com/Yanmife-source/My-Cybersecurity-CTF-writeups-code-and-scripts/File-organiser)** | A script that sorts my Downloads folder by file type into Pictures, Documents, Videos and Music. Built because I was tired of doing it by hand. |
 
I also do freelance bot and automation work.
